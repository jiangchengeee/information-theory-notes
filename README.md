# 信息论基础 复习资料

《信息论基础》（石峰、莫忠息，武汉大学出版社，第三版）这门课的复习材料，
含**从零开始讲起的讲义**、**考前速查笔记**、以及**学期书面作业的详细解答**。
全部用 LaTeX 排版，源码与编译好的 PDF 都在仓库里。

对数底统一取 2，熵与信息量的单位统一为 bit。

### 零基础讲义的分讲结构

| 讲 | 内容 |
|---|---|
| 1 | 先补地基：概率 $p(x)$、边缘/条件分布、期望、$\log_2$ |
| 2 | 自信息 $I(x)=-\log_2 p(x)$：为什么砍一半记 1 bit、为什么必须用 $\log$ |
| 3 | 熵 $H(X)$：加权平均的含义、二元熵函数、$0\le H\le\log n$、唯一性公理 |
| 4 | 联合熵与条件熵：链式法则、条件不增熵、$\Hx{X,Y}\le\Hx{X}+\Hx{Y}$ |
| 5 | 互信息：知道 $Y$ 帮你在 $X$ 上省下多少不确定性 |
| 6 | 连续型随机变量的熵：为什么微分熵可以是负数 |
| 7 | 信道与信道容量：BSC、BEC、强对称信道公式、高斯信道 |
| 8 | 信源编码：Kraft 不等式、Huffman 编码全过程 |
| 9 | 信道编码与汉明码：$2^r\ge n+1$、校验位位置、偶校验方程、伴随式纠错 |
| 10 | 最大熵原理与最小鉴别信息原理 |
| 11 | 组合信息与算法信息（Kolmogorov 复杂度、LZ） |

## 如何编译

需要 TeX Live（含 `ctex`、`tcolorbox`、`booktabs`）与 XeLaTeX：

```bash
# 主讲义（两遍，第二遍生成正确的目录页码）
xelatex 信息论零基础讲义.tex
xelatex 信息论零基础讲义.tex

# 速查笔记 / 作业
xelatex 信息论复习笔记.tex
xelatex 作业1-超详细版.tex
```

若你的 `TEXMFVAR` 目录不可写（某些受管环境），先指定一个可写目录：

```bash
export TEXMFVAR=$PWD/.texmf-var && mkdir -p "$TEXMFVAR"
```

中文字体使用系统自带的 `STSong` / `STHeiti`（macOS）。在 Linux 上编译需把
`ctex` 的 `fontset` 改成 `fandol` 或安装相应中文字体。

## 关于教材与课件

本仓库**不包含**教材扫描件和老师课件的 PDF——那些是他人享有著作权的出版物，
不适合放在公开仓库里。所有笔记内容均为自行整理撰写，公式与结论引用自教材与课堂讲授。

数学上的提醒：`作业1-超详细版` 里第 2.2 题的表述（"奇数以 0.5 的概率等可能地错成
下一个奇数"）教材原文有歧义，文档中给出两种读法及对应答案，答题时写明假设即可。
